# 统计

独立用量分析插件，安装后从「扩展 → 统计」进入，地址为 `/plugin/statistics`，需要 Artificer 1.1.6 或更高版本。

- 总消耗、输入、输出、缓存命中及会话数概览。
- GitHub 风格年度热力图，悬停查看每天的 token 和响应次数。
- 近 7 / 30 / 90 天与全年筛选、最近 30 天趋势、模型排行。
- 工作区与会话消耗排行；工作区可点击筛选，会话可直接打开，回收站会话只展示。
- 点击热力图日期联动当日概览、模型、工作区和会话排行，可与工作区筛选组合。
- 配色跟随宿主主题强调色和亮暗模式，适配窄窗口。

## 数据口径

接口：`GET /api/plugins/statistics/usage?year=2026`。

通过宿主 `ctx.usage.read(year)` 获取只读聚合结果，插件不导入宿主源码或直接访问会话数据库。宿主仅统计已保存且包含用量的 assistant 消息，在缺少自定义标题时截取首条用户消息的标题片段，不读取完整正文、不修改数据库。
总量为输入加输出；缓存命中是输入的子集，不重复计入总量。日期按北京时间归档。
模型名称匹配消息时间所在的运行记录，旧数据或缺少运行记录时展示「未知模型」。
不包含未保存到会话的辅助调用或供应商未上报的用量，因此不作为账单依据。
年内近期筛选以当年今天为结束日；历史年份以 12 月 31 日为结束日。
工作区归属采用当前绑定，不追溯历史移动前的归属。近期趋势保留时间轴以便对照选中日期。
接口缓存 15 秒；无法读取的会话会在界面提示，不影响其余数据展示。
